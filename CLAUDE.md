This website is built using jekyll, it will be hosted on github.io., use https://github.com/alshedivat/al-folio as the template.
In the future, the website will live at the URL: PlatypusWorx.com.
The purpose of the website it to document various projects that I am working on and serve as a portfolio of achivements - as an example, I want to showcase finished projects as well as peer-reviewed published work.

Platypus Worx gets it's name because PlatypusWorks is taken and I want to pay homage to Skunk Works. The platypus is a unique creature with many capabilities, I want to demonstrate that my capabilites rival the platypus's versatility. 

The container is set to auto update on changes, do not run "docker compose down" until I ask for the recent changes to be committed and pushed. When committing, summarize the conversation details and append to claude_summaries.md.

The hsite is meant to document projects. Projects will have a dedicated page in the projects tab, most updates will be in the for of posts. When a post is created for a project, it should also be linked on the bottom of the project page. CelestialSync and Homing a Telescope Mount With Nothing But Gravity is a prime example.
